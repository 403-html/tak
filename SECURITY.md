# Security policy

TAK is experimental. Version 0 streams are not suitable for durable or
security-sensitive storage.

Report a vulnerability with GitHub's private vulnerability reporting feature
for `403-html/tak`. Do not open a public issue before the maintainers have had
an opportunity to assess the report.

Include the affected commit, platform, reproduction input, expected behavior,
and observed behavior. State whether the issue can cause memory exhaustion,
excessive CPU use, a crash, data corruption, or unsafe file-system access.

There are no stable supported releases yet. The maintainers will publish the
affected versions and remediation status when the first release exists.
