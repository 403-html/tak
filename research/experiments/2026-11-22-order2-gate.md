# Accepted gate: adaptive second-order context

## Status

RFC 0002 Phase A passed. The specified three-core tensor experiment is
authorized. No TAK-C method identifier is assigned.

## Hypothesis and control

The rejected RFC 0001 model cannot distinguish two sequences that have the same
immediately preceding byte but different second preceding bytes. Phase A tests
whether `P(next | previous two bytes)` contains enough useful information to
justify a factorized tensor experiment.

The control is a deterministic adaptive order-2 byte model. It lazily allocates
distributions for observed two-byte contexts. Every complete `TKO2` artifact
contains a 28-byte header, arithmetic-coded payload, and checksum. It transmits
no model parameters.

## Method

- Base commit: `d5baa43`, plus the RFC 0002 Phase A implementation.
- Compiler: Rust 1.85.0, release profile.
- CPU: Intel Xeon Platinum 8573C, x86-64.
- OS: Linux 6.18.57.
- Threads: one.
- Samples: one screening run per input after release build.
- Verification: exact byte-for-byte restoration for both controls.
- Order-1 size: complete TAK-C frame.
- Order-2 size: complete `TKO2` artifact.

`enwik8` used its final 10,000,000 bytes. Each Silesia file used its final 10%
after integer truncation. Input digests and mirror provenance are recorded in
the earlier `enwik8` and Silesia experiment reports.

This is a gate measurement, not a publication-quality benchmark.

The complete `enwik8` experiment process peaked at 155,492 KiB. This is a
conservative upper bound because the process simultaneously held the 100 MB
source, tensor screening state, both encoded controls, and decoded outputs. It
is below the one-gigabyte decoder target.

## Gate decision

The control passes every gate:

1. It is smaller on all tested groups, exceeding the required three.
2. Every reduction exceeds 2%.
3. The measured process upper bound is below one gigabyte.
4. Every decoder slowdown is below 2x.
5. Unit tests cover round trips, truncation, corruption, and output limits.

Proceed with RFC 0002 Phase B. Implement only the three-core dependency and
ranks specified by the RFC. Compare complete tensor artifacts against both
order-1 and order-2. Stop if tensor parameter sharing does not recover its
metadata or cannot approach the order-2 control.
