# Rejected gate: adaptive third-order context

## Status

RFC 0003 is rejected. No third-order tensor implementation is authorized.

## Hypothesis

The byte at position `t-3` might change the next-byte distribution after the
two more recent bytes are fixed. An adaptive order-3 control would then produce
a complete artifact at least 2% smaller than adaptive order-2 on three or more
dataset groups.

## Method

- Base commit: `50ee56f`, plus the RFC 0003 implementation.
- Dataset: final 10% of five Silesia files after an integer 90% split.
- Source: `https://github.com/MiloszKrajewski/SilesiaCorpus`.
- Order-2 artifact: complete `TKO2` header, arithmetic payload, and checksum.
- Order-3 artifact: complete `TKO3` header, arithmetic payload, and checksum.
- Order-3 storage: exact sparse frequency increments with implicit frequency
  one for every byte.
- CPU: Intel Xeon Platinum 8573C, x86-64, three visible logical CPUs.
- OS: Linux 6.18.57.
- Compiler: Rust 1.85.0.
- Threads: one.
- Samples: one screening run per input.
- Verification: exact byte-for-byte restoration for both artifacts.

These are non-publishable screening measurements. The run did not include a
warm-up or five repetitions. Peak resident memory is the maximum for the
complete runner process, which sequentially encoded and decoded both controls.
It is a conservative decoder upper bound, not an isolated decoder measurement.

## Decision

Reject RFC 0003. Order-3 fails the size condition on every input and the
decoder-speed condition on every input. The memory condition passes, but it
does not compensate for the other failures.

The likely cause is sparse-context fragmentation. Every new three-byte context
starts with 256 implicit pseudocounts, so evidence accumulates more slowly than
in the shared order-2 distributions. This experiment does not show that the
third preceding byte has no information. It shows that the tested independent
order-3 distributions cannot use that information efficiently.

Do not build a four-core tensor train or increase rank. The next relevant
experiment should be classical escape or backoff modeling that measures
whether mature three-byte contexts add value while rare contexts reuse shorter
history. Any later tensor proposal still needs a new mechanism and stop
condition that address RFC 0002's factorization loss.
